## 附录：代码与文档不一致的详细核实

### 文档声称（methods.md第2.3节）

```
有效传播率公式：
β_eff(t) = β_base × (1 - ε × P_avg(t))

其中：
- β_eff(t)：第t天的有效传播率
- β_base：基础传播率（0.3）
- ε：防护效率（0.85）
- P_avg(t)：第t天的平均防护水平
```

### 实际代码（hybrid_model.py第137行）

```python
# 计算全人群平均防护水平（用于感染概率）
total_protection = sum(agent.protection_level for agent in self.agents)
avg_protection = total_protection / self.population_size
effective_beta = self.seir_params.beta_base * (1 - avg_protection)
```

### 核实结果

**问题**：
- 代码中**没有**防护效率参数ε
- 代码实现为 `effective_beta = beta_base * (1 - avg_protection)`
- 这等价于 `ε = 1.0`，而不是文档声称的 `ε = 0.85`

**影响**：
- 文档描述的公式与代码实现**完全不一致**
- 所有基于文档公式的理论推导都是**无效的**
- 所有实验结果都是基于**错误的代码**

**建议**：
1. **立即修正代码**：添加防护效率参数ε=0.85
