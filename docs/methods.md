# 方法

## 2.1 信息显著性理论框架

### 2.1.1 概念定义

**信息显著性**（Informational Saliency）定义为疫情信息在个体认知中的突出程度，由以下因素决定：

1. **基础显著性**：感染比例（I/N）
2. **媒体放大效应**：媒体报道强度和频率
3. **时间衰减**：信息疲劳导致的显著性下降

形式化表达为：

```
S(t) = min(1.0, (I(t)/N) × α × exp(-λ × t/100))
```

其中：
- S(t)：第t天的信息显著性 [0, 1]
- I(t)：第t天的感染人数
- N：总人口
- α：媒体放大系数（media_amplification）
- λ：衰减率（decay_rate）

### 2.1.2 风险感知模型

个体风险感知由三个来源加权综合：

```
R_target(t) = w_info × S(t) + w_social × I_social(t) + w_personal × P(t)
```

其中：
- w_info = 0.6：信息显著性权重
- w_social = 0.3：社会影响权重（周围人感染比例）
- w_personal = 0.1：个人经历权重（是否感染或接触感染者）

**行为惯性**：风险感知采用指数平滑更新

```
R(t) = (1 - η) × R_target(t) + η × R(t-1)
```

其中 η = 0.3 为惯性系数。

### 2.1.3 防护行为模型

防护行为采用S型响应函数：

```
P(t) = 1 / (1 + exp(-κ × (R(t) - 0.5)))
```

其中 κ = 1.5 为敏感度参数。

## 2.2 混合仿真架构

### 2.2.1 三层耦合框架

本研究构建了 **ABM + SD + DES** 三层耦合的混合仿真框架：

**ABM层（Agent-Based Model）**：
- 个体Agent：每个Agent具有状态（S/E/I/R）、风险感知、防护行为
- 状态转移：基于感染概率的随机转移
- 行为决策：基于风险感知的防护行为

**SD层（System Dynamics）**：
- SEIR模型：S（易感）→ E（潜伏）→ I（感染）→ R（恢复）
- 信息传播：信息显著性动态
- 风险感知：宏观风险水平

**DES层（Discrete Event Simulation）**：
- 医疗资源：医院床位、ICU床位
- 排队系统：检测排队、住院排队
- 容量约束：资源上限

### 2.2.2 耦合机制

**ABM → SD**：
- 聚合个体状态 → 宏观SEIR统计
- 聚合防护行为 → 平均防护水平

**SD → ABM**：
- 宏观信息显著性 → 个体风险感知
- 平均防护水平 → 有效传播率

**ABM → DES**：
- 个体就医需求 → 资源请求

**DES → ABM**：
- 资源可用性 → 就医结果

### 2.2.3 有效传播率

关键创新：防护行为动态影响传播率

```
β_eff(t) = β_base × (1 - ε × P_avg(t))
```

其中：
- β_base：基础传播率（默认0.3）
- ε：防护效率（protection_efficiency，默认0.85）
- P_avg(t)：第t天全人群平均防护水平

**防护效率参数ε的意义**：即使100%人群采取防护措施，仍有15%的残余传播风险。这反映了防护措施的不完美性（如口罩佩戴不规范、社交距离执行不严格等）。

### 2.2.4 蚊媒动态模块（登革热特有）

登革热通过蚊子传播，因此模型包含蚊媒动态模块：

**蚊媒传播机制**：
1. 感染人类 → 蚊子叮咬 → 蚊子感染
2. 蚊子体内病毒发育（外潜伏期，10天）
3. 感染蚊子 → 叮咬易感人群 → 人类感染

**蚊媒参数**：

| 参数 | 符号 | 默认值 | 说明 |
|------|------|--------|------|
| 蚊子种群数量 | M | 5000 | 环境中的蚊子总数 |
| 叮咬率 | b | 0.3 | 每只蚊子每日叮咬概率 |
| 人传蚊概率 | p_hm | 0.5 | 叮咬感染者后蚊子感染的概率 |
| 蚊传人概率 | p_mh | 0.4 | 感染蚊子叮咬后人类感染的概率 |
| 蚊子寿命 | L_m | 14 | 蚊子平均寿命（天） |
| 外潜伏期 | EIP | 10 | 病毒在蚊子体内发育时间（天） |
| 季节性因子 | s | 1.0 | 根据月份调整的传播因子 |

**蚊媒传播风险**：

```
mosquito_risk(t) = b × p_mh × I_mosquito(t) / M × s
```

其中I_mosquito(t)是第t天的感染蚊子数量。

**总感染概率**：

```
P_infection = min(1.0, human_transmission + mosquito_transmission)
```

其中：
- human_transmission = β_eff(t) × I(t) / N
- mosquito_transmission = mosquito_risk(t)

## 2.4 实验设计

### 2.4.1 实验1：概念验证

**目标**：验证信息-行为反馈机制的存在性

**设计**：
- 实验组：启用信息-行为反馈（enable_info_behavior_feedback=True）
- 对照组：禁用信息-行为反馈（enable_info_behavior_feedback=False）
- 人口规模：N=1000
- 仿真天数：200天
- 初始感染：5人

**测量指标**：
- 峰值感染人数
- 峰值出现时间
- 总感染人数
- 感染比例

### 2.4.2 实验2：定量对比

**目标**：量化信息显著性的独立效应

**设计**：
- 20次重复实验
- 实验组：完整信息-行为耦合
- 对照组：防护水平固定为0（等效于传统SEIR）
- 统计检验：t检验、Cohen's d效应量

**测量指标**：
- 峰值感染（均值±标准差）
- 总感染（均值±标准差）
- 效应量（Cohen's d）
- 显著性水平（p值）

### 2.4.3 实验3：参数敏感性

**目标**：分析媒体放大系数的影响

**设计**：
- 媒体放大系数：α ∈ {0.5, 1.0, 1.5, 2.0, 3.0, 5.0}
- 每组10次重复
- 测量峰值感染和总感染

**测量指标**：
- 峰值感染（均值±标准差）
- 峰值降低百分比
- 总感染（均值±标准差）
- 总感染降低百分比

### 2.4.4 实验4：数据校准

**目标**：使用真实登革热数据校准模型参数

**数据源**：OpenDengue数据集（巴西，2015-2023）

**校准方法**：
- 参数网格搜索
- 目标函数：最小化RMSE
- 验证指标：R²决定系数

**校准参数**：
- β_base ∈ [0.1, 0.5]
- σ ∈ [0.1, 0.3]
- γ ∈ [0.05, 0.2]
