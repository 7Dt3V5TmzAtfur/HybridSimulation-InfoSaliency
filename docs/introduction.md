# 引言

## 1.1 研究背景

登革热是全球传播最快的蚊媒病毒病，每年影响超过100个国家，约39亿人面临感染风险（Kraemer et al., 2019）。近年来，随着气候变化和城市化进程加速，登革热发病率和地理分布范围持续扩大。世界卫生组织（WHO）数据显示，全球登革热病例在过去50年间增长了30倍，已成为重大公共卫生威胁。

**关键挑战**：
- 缺乏有效疫苗和特效药物
- 传播媒介（埃及伊蚊）控制困难
- 公众防护行为难以持续
- 医疗资源在疫情期间易过载

## 1.2 信息-行为-疫情耦合机制

传统传染病模型（如SEIR）假设传播率β为常数或简单时间函数，忽略了**信息驱动的行为改变**对传播动态的反馈效应。然而，真实世界中，疫情信息通过媒体、社交网络传播，改变公众风险感知，进而驱动防护行为（如防蚊措施、就医行为），最终影响疫情曲线。

**核心洞察**：
- 疫情信息通过媒体、社交网络传播 → 改变公众风险感知
- 风险感知驱动防护行为（防蚊措施、就医行为）
- 防护行为降低有效传播率 → 影响疫情曲线
- 疫情实际状态更新信息环境 → 形成反馈循环

## 1.3 研究空白

现有研究存在三个关键空白：

1. **概念空白**：缺乏"信息显著性"的形式化定义和测量框架。现有研究多关注视觉显著性（Itti-Koch模型），但疫情信息的"显著性"如何量化尚未建立理论框架。

2. **方法空白**：未构建信息-物理耦合的混合仿真框架（ABM+SD+DES）。现有传染病模型多为单一范式（纯ABM或纯SD），缺乏多层耦合的混合仿真方法。

3. **理论空白**：未揭示信息显著性通过行为反馈"压平曲线"的机制。现有研究多关注物理传播机制，缺乏对信息-行为-传播耦合动力学的深入分析。

## 1.4 研究目标

本研究旨在构建**信息显著性驱动的登革热混合仿真框架**，量化信息-行为-疫情的耦合动力学，为公共卫生干预策略提供科学依据。

**具体目标**：
1. **概念扩展**：将"显著性"从视觉领域扩展到**信息显著性**（Informational Saliency）
2. **混合仿真架构**：构建ABM+SD+DES三层耦合的混合仿真框架
3. **机制验证**：量化信息显著性对疫情控制的独立效应
4. **实证校准**：使用真实登革热数据校准模型参数
5. **政策建议**：优化疫情信息发布策略和医疗资源配置
