# 研究框架：信息显著性驱动的登革热混合仿真

## 一、研究背景与动机

### 1.1 登革热全球负担

登革热是全球传播最快的蚊媒病毒病，每年影响超过100个国家，约39亿人面临感染风险。近年来，随着气候变化和城市化进程加速，登革热发病率和地理分布范围持续扩大。

**关键挑战**：
- 缺乏有效疫苗和特效药物
- 传播媒介（埃及伊蚊）控制困难
- 公众防护行为难以持续
- 医疗资源在疫情期间易过载

### 1.2 信息-行为-疫情耦合机制

传统传染病模型（如SEIR）假设传播率β为常数或简单时间函数，忽略了**信息驱动的行为改变**对传播动态的反馈效应。

**核心洞察**：
- 疫情信息通过媒体、社交网络传播 → 改变公众风险感知
- 风险感知驱动防护行为（防蚊措施、就医行为）
- 防护行为降低有效传播率 → 影响疫情曲线
- 疫情实际状态更新信息环境 → 形成反馈循环

### 1.3 研究空白

现有研究的三个关键空白：

1. **概念空白**：缺乏"信息显著性"的形式化定义和测量框架
2. **方法空白**：未构建信息-物理耦合的混合仿真框架（ABM+SD+DES）
3. **理论空白**：未揭示信息显著性通过行为反馈"压平曲线"的机制

## 三、理论框架

### 3.1 信息显著性理论

**定义**：信息显著性（Informational Saliency）是疫情信息在个体认知中的突出程度，由以下因素决定：

- **信息强度**：病例数、死亡率、医疗资源紧张度
- **媒体放大**：新闻报道频率、社交媒体传播度
- **个人相关性**：周围人感染情况、地理位置接近度
- **时效性**：信息新鲜度、更新频率

**形式化表达**：

```
S(t) = f(I(t)/N, M(t), P(t), T(t))
```

其中：
- S(t): t时刻的信息显著性
- I(t)/N: 感染比例
- M(t): 媒体放大系数
- P(t): 个人相关性
- T(t): 时效性衰减

### 3.2 风险感知模型

**风险感知**（Risk Perception）是个体对感染风险的主观评估，由三个来源加权综合：

```
R_i(t) = w_info * S(t) + w_social * Social_i(t) + w_personal * Personal_i(t)
```

其中：
- w_info: 信息权重（默认0.6）
- w_social: 社会影响权重（默认0.3）
- w_personal: 个人经历权重（默认0.1）

**行为惯性**：风险感知更新具有惯性，避免剧烈波动

```
R_i(t+1) = (1 - α) * R_target + α * R_i(t)
```

其中α为惯性系数（默认0.3）

### 3.3 行为决策模型

**防护行为**（Protection Level）由风险感知驱动，采用S型响应函数：

```
P_i(t) = 1 / (1 + exp(-k * (R_i(t) - 0.5)))
```

其中k为敏感度参数（默认1.5）

**行为效应**：防护水平降低有效传播率

```
β_eff(t) = β_base * (1 - P_avg(t))
```

其中P_avg(t)为平均防护水平

## 四、混合仿真架构

### 4.1 ABM层：个体行为

**Agent属性**：
- 状态：S（易感）、E（潜伏）、I（感染）、R（康复）
- 风险感知：[0, 1]
- 防护水平：[0, 1]
- 信息显著性感知：[0, 1]
- 感染天数、潜伏天数
- 检测状态、住院状态

**行为规则**：
1. 每日更新信息显著性感知
2. 综合信息、社会影响、个人经历更新风险感知
3. 基于风险感知决定防护水平
4. 根据防护水平调整感染概率
5. 感染后根据严重程度决定是否就医

### 4.2 SD层：宏观动力学

**SEIR模型**：
```
dS/dt = -β_eff * S * I / N
dE/dt = β_eff * S * I / N - σ * E
dI/dt = σ * E - γ * I
dR/dt = γ * I
```

**信息传播模型**（扩展）：
```
dInfoS/dt = -λ * InfoS * I / N
dInfoI/dt = λ * InfoS * I / N - δ * InfoI
dInfoR/dt = δ * InfoI
```

其中：
- InfoS: 信息易感者（未接触疫情信息）
- InfoI: 信息感染者（主动传播疫情信息）
- InfoR: 信息康复者（不再传播信息）

### 4.3 DES层：医疗资源

**检测排队**：
- 每日检测容量：100人
- 检测结果时间：1天
- 队列管理：FIFO（先到先服务）

**住院排队**：
- 普通床位：200张
- ICU床位：50张
- 平均住院时间：7天（普通）、14天（ICU）
- 容量溢出：记录被拒绝入院人数

**事件调度**：
- 每日处理出院事件
- 每日处理检测完成事件
- 每日处理等待队列（如有床位释放）

## 五、研究问题

### 5.1 核心研究问题

**RQ1**：信息显著性能否通过行为反馈显著降低登革热疫情峰值？

**假设**：信息显著性驱动的防护行为可以降低有效传播率，从而"压平曲线"

**验证方法**：
- 对比实验：启用/禁用信息-行为反馈
- 效应量阈值：峰值降低>20%

### 5.2 扩展研究问题

**RQ2**：媒体放大系数如何影响疫情控制效果？

**假设**：媒体放大系数越高，信息显著性越强，疫情控制效果越好

**验证方法**：
- 参数敏感性分析：测试0.5-5.0的媒体放大系数
- 阈值分析：确定达到20%效应量的临界值

**RQ3**：信息-行为反馈存在哪些涌现行为？

**假设**：存在时滞效应、多峰现象等涌现特性

**验证方法**：
- 时间序列分析：识别信息峰值与防护峰值的时滞
- 相图分析：识别多峰现象和振荡行为

**RQ4**：如何校准模型以拟合真实登革热数据？

**假设**：通过参数优化可以使模型拟合真实疫情曲线

**验证方法**：
- 使用OpenDengue数据集进行参数校准
- 训练集/测试集分割验证泛化能力

**目标**：验证混合仿真框架可行性

**输出指标**：
- SEIR曲线
- 信息显著性时间序列
- 风险感知和防护水平时间序列
- 医疗资源使用情况

### 6.2 实验2：信息效应定量对比

**目标**：量化信息显著性的独立效应

**设计**：
- 实验组：启用信息-行为反馈
- 对照组：禁用信息-行为反馈（防护水平固定为0）
- 重复次数：10次（取平均）

**输出指标**：
- 峰值感染（均值±标准差）
- 总感染（均值±标准差）
- 效应量（峰值降低%、总感染降低%）
- 统计显著性检验（t检验）

### 6.3 实验3：参数敏感性分析

**目标**：分析媒体放大系数的影响

**设计**：
- 测试参数：[0.5, 1.0, 1.5, 2.0, 3.0, 5.0]
- 每个参数运行10次仿真

**输出指标**：
- 峰值感染 vs 媒体放大系数
- 峰值降低 vs 媒体放大系数
- 总感染 vs 媒体放大系数
- 峰值日 vs 媒体放大系数
- 最大防护水平 vs 媒体放大系数

### 6.4 实验4：登革热数据校准

**目标**：使用真实数据校准模型参数

**设计**：
- 数据集：OpenDengue（巴西，2015-2023）
- 优化方法：L-BFGS-B
- 验证方法：训练集/测试集分割（80%/20%）

**输出指标**：
- 最优参数：beta_base, sigma, gamma, media_amplification
- 拟合指标：RMSE, R²
