# 讨论

## 5.1 主要发现

### 5.1.1 信息-行为反馈机制的有效性

本研究的核心发现是：**信息-行为反馈机制可以有效"压平曲线"**。

**实验证据**：
- 实验1：峰值降低51.5%，总感染降低18.6%
- 实验2：峰值降低34.3%（p = 2.28×10⁻²¹, Cohen's d = 6.32），总感染降低6.9%（p = 4.89×10⁻²⁶, Cohen's d = 8.56）
- 消融实验：禁用行为反馈导致峰值感染**上升130人**（从126升至219）

**机制解释**：
1. 疫情信息通过媒体传播 → 提高信息显著性
2. 信息显著性提高 → 增强风险感知
3. 风险感知增强 → 驱动防护行为（防蚊措施、就医行为）
4. 防护行为提高 → 降低有效传播率 β_eff(t) = β_base × (1 - P_avg(t))
5. 传播率降低 → 减少新感染 → 压平疫情曲线

**理论贡献**：
- 首次将"显著性"从视觉领域扩展到信息领域
- 建立了信息显著性的形式化定义和测量框架
- 揭示了信息-行为-传播的耦合动力学

### 5.1.2 媒体放大系数的有限影响

本研究的意外发现是：**媒体放大系数对疫情控制的影响有限**。

**实验证据**：
- 实验3：媒体放大系数α从0.5增加到5.0，峰值降低仅0-10.63%
- 未达到20%阈值
- 防护水平提高23.6%（0.347→0.429），但未转化为显著的疫情控制效果

**可能原因**：
1. **非线性效应**：防护行为采用S型响应函数，存在饱和效应
2. **行为惯性**：风险感知更新存在惯性（η=0.3），限制了快速响应
3. **信息疲劳**：信息显著性随时间衰减（λ=0.1），长期效果减弱

**实践启示**：
- 单纯增加媒体报道强度不是最优策略
- 需要探索其他调控机制（如行为惯性、风险感知权重）
- 信息发布的时机和内容可能比强度更重要

### 5.1.3 参数校准的挑战

本研究发现：**使用真实数据校准模型存在显著挑战**。

**实验证据**：
- 实验4：R² = -1.430（负值）
- 模型拟合劣于简单均值基线
- 校准实质失败

**可能原因**：
1. **模型结构过于简化**：
   - 缺乏空间异质性（不同地区的传播动态差异）
   - 缺乏季节性因素（登革热具有明显的季节性）
   - 缺乏蚊媒动态（未显式建模蚊子种群）

2. **参数网格范围不足**：
   - β_base ∈ [0.1, 0.5]，可能未覆盖真实值
   - σ ∈ [0.1, 0.3]，γ ∈ [0.05, 0.2]，范围较窄

3. **数据预处理问题**：
   - OpenDengue数据可能存在缺失值、异常值
   - 数据聚合方式可能引入偏差

**改进方向**：
- 添加季节性因素（温度、降水）
- 扩展参数搜索空间
- 使用更复杂的优化算法（如贝叶斯优化、遗传算法）
- 改进数据预处理流程

## 5.4 局限性

### 5.4.1 模型简化

1. **均匀混合假设**：
   - 模型假设人群均匀混合
   - 未考虑空间异质性（不同地区的传播动态差异）
   - 未考虑接触网络结构（家庭、学校、工作场所）

2. **缺乏蚊媒动态**：
   - 未显式建模蚊子种群
   - 未考虑季节性因素（温度、降水）
   - 可能导致参数校准失败（R² = -1.430）

3. **简化的行为模型**：
   - 防护行为采用S型响应函数
   - 未考虑个体异质性（年龄、职业、风险偏好）
   - 未考虑社会规范和文化因素

### 5.4.2 数据限制

1. **校准数据不足**：
   - 仅使用巴西2015-2023年数据
   - 样本量有限
   - 可能存在数据质量问题（缺失值、异常值）

2. **参数校准失败**：
   - R² = -1.430（负值）
   - 模型拟合劣于简单均值基线
   - 需要改进模型结构和校准方法

3. **缺乏实证验证**：
   - 未使用真实疫情数据验证模型预测
   - 未与真实防控策略效果对比
   - 需要进一步的实证研究

### 5.4.3 计算限制

1. **计算成本**：
   - 大规模人群模拟（N=1000）需要较长时间
   - 参数网格搜索计算量大
   - 限制了更复杂的模型结构和更大的参数空间

2. **随机性**：
   - 模型包含随机因素（感染概率、状态转移）
   - 需要多次重复实验进行统计检验
   - 增加了计算成本
