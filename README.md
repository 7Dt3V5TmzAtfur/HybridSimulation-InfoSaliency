# 信息显著性驱动的登革热混合仿真模型

## 一句话总结

**内生防护行为（平均防护≈0.34）能有效压平疫情曲线（N=1000 峰值降低 35.9%，p=8.5×10⁻²¹；N=10⁴ 为 24.8%）；效应分解显示防护水平本身承载约 95%（N=1000）/85%（N=10⁴）的效应——机制对照进一步定位：同一骨架下 awareness 扩散模块动态边际 +22.5pp（显著），本文显著性通道仅 +1.7pp（ns），根源是 S 型响应饱和而非"动态不重要"。**

## 项目概述

本项目实现了一个**信息显著性驱动的传染病混合仿真框架**，将 **ABM（Agent-Based Model）+ SD（System Dynamics）+ DES（Discrete Event Simulation）+ 蚊媒动态**四层耦合，用于模拟登革热传播过程中信息-行为-疫情的动态交互。

### 核心创新

1. **概念扩展**：将"显著性"从视觉领域扩展到**信息显著性**（Informational Saliency），给出可计算的形式化定义
2. **四层混合仿真架构**：
   - **ABM层**：个体行为决策（信息感知 → 风险感知 → 防护行为）
   - **SD层**：宏观流行病动力学（SEIR模型 + 信息传播）
   - **DES层**：医疗资源约束（检测排队、住院/ICU 排队、延后入院记账）
   - **蚊媒动态层**：人-蚊-人传播（外潜伏期显式建模），**蚊媒通道与人际通道均受防护水平调制**
3. **防护效率参数 ε=0.85**：即使 100% 人群采取防护，仍有 15% 残余传播风险（建模假设）
4. **效应分解实验设计**：恒定防护对照 + 配对种子消融，分离"防护水平本身"与"信息驱动的动态调制"
5. **确定性等效系统校准**：与 ABM 期望动力学同构的替代系统上做网格搜索 + 报告率闭式估计，再代入 ABM 复核

### 关键发现

- ✅ **内生防护行为有效压平曲线**：峰值感染降低 35.9%（142.6 vs 222.4，p=8.5×10⁻²¹，Welch t=-19.49），总感染降低 7.1%（p=2.1×10⁻¹⁵）；效应稳健于行为参数（κ≤1.5 时峰值降低 36%–47%）
- ✅ **效应分解（诚实边界）**：恒定防护 P*=0.336 复现整体峰值下降的约 95%（36.3% vs 38.3%）；动态信息-行为反馈的边际贡献 3.2 个百分点且不显著（p=0.282）。机制：S 型响应在低风险区已饱和（风险≈0 时防护≈0.32）
- ✅ **真实数据校准成功**：OpenDengue 巴西 2019 周报（52 周），确定性等效系统网格搜索 **R²=0.941**（β=0.25，γ=0.1，人类通道 R₀=2.50，有效报告率 ρ=1.14%）；替代系统与 ABM 周发病率相关 r=0.967；冻结参数跨季外推：大疫情季 0.79–0.94、小疫情年失败（形状边界）
- ✅ **规模外部效度**：N=10⁴ 复核——峰值降低 24.8%（小种群随机衰减消失），分解方向不变（恒定防护复现 85%），动态边际转为显著（4.5pp）；总感染效应因攻击率饱和近于消失
- ✅ **机制对照（awareness 基线）**：同一传播骨架、匹配平均防护下，prevalence 驱动的 awareness 扩散模块动态边际 +22.5pp（p<0.001）vs 本文 +1.7pp（ns）——本文机制动态无效的根源是响应函数饱和，改进路径明确
- ⚠️ **媒体放大边际效应有限**：达到预设的"峰值降低≥20%"标准需要 α≥5（参照 α=0.5 的 10 倍）
- ✅ **消融归因**：行为反馈为承重组件（移除后峰值 +47.4%）；信息显著性单通道贡献在噪声内（−3.2%）；医疗资源约束不影响传播（0.0%）、仅作用于延后入院指标（−100%）；蚊媒通道贡献峰值约 5.4%

## 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 数据

真实数据已随仓库提供：`data/National_extract_V1_3.csv`（OpenDengue v1.3 国家级抽取）。
下载与格式说明见 `data/README.md`。

### 3. 运行实验（按统一再生协议）

```bash
python experiments/exp01_concept_validation.py        # 概念验证
python experiments/exp02_info_effect_comparison.py    # 定量对比（头条统计）
python experiments/exp03_parameter_sensitivity.py     # 媒体放大敏感性 + 阈值分析
python experiments/exp04_dengue_calibration.py        # 真实数据校准
python experiments/exp05_protection_decomposition.py  # 防护分解（恒定防护对照）
python experiments/exp06_behavior_sensitivity.py      # 行为参数敏感性
python experiments/exp07_scale_validation.py          # 规模外部效度（N=10⁴）
python experiments/exp08_awareness_baseline.py        # 机制对照（awareness 基线）
python experiments/ablation_attribution.py            # 消融归因审计
python scripts/verify_consistency.py                  # 一致性校验（亦为 pre-commit 钩子）
```

**种子协议**：每次运行独立种子 `seed = BASE_SEED×1000 + run_index`（各实验 BASE_SEED 见 `experiments/protocol.py`）。请勿改回"全局单种子"——那会使多次重复失去独立性。

## 核心模型说明

### 混合仿真架构

```
┌─────────────────────────────────────────────────────────┐
│  ABM层：个体行为                                          │
│  - 信息显著性感知模块（新闻、社交、周围感染）              │
│  - 风险感知 → 行为决策（防护、检测、就医）                 │
│  - 个体状态转移（S/E/I/R）                               │
└─────────────────────────────────────────────────────────┘
          ↓ 聚合统计                    ↑ 个体状态
┌─────────────────────────────────────────────────────────┐
│  SD层：宏观动力学                                         │
│  - SEIR流行病模型（S→E→I→R）                             │
│  - 信息传播模型（信息显著性动态）                          │
│  - 风险感知动态（惯性、疲劳）                              │
└─────────────────────────────────────────────────────────┘
          ↓ 资源需求                    ↑ 资源约束
┌─────────────────────────────────────────────────────────┐
│  DES层：医疗资源系统                                      │
│  - 检测排队（采样→检测→出结果）                           │
│  - 住院/ICU 排队（延后入院=唯一病人数记账）                │
│  - 资源容量约束（床位、ICU、医护）                         │
└─────────────────────────────────────────────────────────┘
          ↕ 人-蚊-人传播（双通道均受防护调制）
┌─────────────────────────────────────────────────────────┐
│  蚊媒动态层（登革热特有）                                  │
│  - 蚊群：易感/潜伏/感染（外潜伏期 10 天显式建模）           │
│  - 叮咬传播：人→蚊→人                                     │
└─────────────────────────────────────────────────────────┘
```

**有效传播率（双通道防护调制）**：

```
β_eff(t)  = β_base × (1 - ε × P_avg(t))          # 人际通道
risk_eff(t) = risk(t) × (1 - ε × P_avg(t))       # 蚊媒通道
```

其中 ε=0.85（防护效率），P_avg(t) 为全人群平均防护水平。

### 关键参数

| 参数 | 说明 | 默认值 | 范围 |
|------|------|--------|------|
| `beta_base` | 基础传播率（人际通道） | 0.3 | [0.1, 0.5] |
| `sigma` | 潜伏期倒数 | 0.2 | [0.1, 0.5] |
| `gamma` | 恢复率倒数 | 0.1 | [0.05, 0.2] |
| `protection_efficiency` | 防护效率 ε | 0.85 | 建模假设 |
| `media_amplification` | 媒体放大系数 α | 1.0 | [0.5, 5.0]（阈值分析至 10） |
| `hospital_beds` | 医院床位数 | 200 | 消融实验收紧至 50 |
| `icu_beds` | ICU 床位数 | 50 | 消融实验收紧至 10 |
| `mosquito_population` | 蚊群规模 | 5000 | 按蚊/人比例 5:1 随人口缩放 |

## 实验结果

### 实验1：概念验证（20 次重复/组，α=1.0，初始感染 10 人）

| 指标 | 实验组（均值±标准差） | 对照组（均值±标准差） | 效应 |
|------|----------------------|----------------------|------|
| 峰值感染 | 143.7 ± 10.4 | 220.8 ± 15.2 | **↓34.9%** |
| 峰值日 | 68.6 ± 9.9 | 50.1 ± 4.9 | 延迟 18.6 天 |
| 总感染 | 888.4 ± 17.3 | 968.2 ± 7.0 | **↓8.2%** |

### 实验2：定量对比（20 次重复/组，Welch t + Cohen's d）

| 指标 | 实验组 | 对照组 | 降低 | Welch t | p 值 | Cohen's d [95% CI] |
|------|--------|--------|------|---------|-----|--------------------|
| 峰值感染 | 142.55 ± 11.44 | 222.35 ± 14.30 | **35.89%** | -19.49 | 8.5×10⁻²¹ | -6.16 [-8.25, -5.15] |
| 总感染 | 895.55 ± 17.77 | 964.35 ± 9.44 | **7.13%** | -15.29 | 2.1×10⁻¹⁵ | -4.84 [-6.37, -4.11] |

**注意**：对照组为"防护=0"，效应量度量的是"有无内生防护行为"的整体差异，Cohen's d 的量级由该对照设置放大；单通道分解见实验5与消融。

### 实验3：媒体放大系数敏感性（10 次重复/组）

| α | 峰值感染 | 峰值降低 | 总感染降低 |
|---|---------|---------|-----------|
| 0.5 | 150.0 ± 17.3 | 0.0%（参照） | 0.0% |
| 1.0 | 135.6 ± 16.4 | 9.60% | 1.14% |
| 1.5 | 142.7 ± 10.8 | 4.87% | 1.47% |
| 2.0 | 138.1 ± 19.5 | 7.93% | 1.32% |
| 3.0 | 134.2 ± 10.7 | 10.53% | 2.30% |
| 5.0 | 120.0 ± 13.3 | **20.00%** | 4.45% |

**结论**：达到预设的 20% 峰值降低标准（项目研究框架事先约定）需要 α≥5（参照的 10 倍）。单纯增强媒体强度不是高杠杆策略。

### 实验4：真实数据校准（OpenDengue 巴西 2019 周报，52 周）

- 确定性等效系统（与 ABM 期望动力学同构）网格搜索：β=0.25，σ=0.10，γ=0.10，α=1.0，I₀=5×10⁵
- **R² = 0.941**（RMSE=10,078 周病例）；有效报告率 ρ=1.14%；人类通道 R₀=2.50
- ABM 复核（N=1 万，5 次重复）：周发病率相关 r=0.967，96% 周次落在 ±2σ 内
- 多季节外推（冻结动力学参数）：大疫情季 R²=0.79–0.94（2022/2023/2016 宽松档），小疫情年 2017 与异形年 2018 失败——校准可转移性以此为界
- 限定：σ 落在网格下界（无季节调制下的形状补偿），不应作生物学解读

### 实验5：防护分解（恒定防护对照，20 次重复/臂）

| 臂 | 峰值感染 | 峰值降低 | 总感染降低 |
|----|---------|---------|-----------|
| 零防护 | 230.2 ± 15.7 | 0% | 0% |
| 恒定防护 P*=0.336 | 146.8 ± 15.3 | 36.3% | 8.5% |
| 完整模型（动态） | 142.1 ± 11.2 | 38.3% | 8.9% |

**结论**：动态信息-行为反馈的边际贡献 = 3.2 个百分点（p=0.282，不显著），占整体下降的约 8.3%。机制：S 型响应中点在 R=0.5，低风险区防护已≈0.32（近饱和）。**N=10⁴ 复核**（exp07）：峰值降低 24.8%、恒定防护复现 85%、动态边际 4.5pp 转为显著（p=1.6×10⁻⁸）；总感染效应因攻击率饱和近于消失（1.4%）。

### 实验8：机制对照（awareness 扩散基线，匹配平均防护，10 次重复/臂）

| 机制 | 零防护峰值 | 恒定 | 动态 | 动态边际 |
|------|-----------|------|------|---------|
| awareness 扩散（m\*=0.497） | 221.0±12.6 | 144.5±13.5（+34.6%） | 112.0±14.2（**+49.3%**） | **+22.5pp（p=5.5×10⁻⁵）** |
| 本文显著性机制 | 218.7±18.5 | 148.8±13.8（+32.0%） | 146.2±11.8（+33.2%） | +1.7pp（p=0.656） |

**结论**：同一骨架、匹配平均防护下，prevalence 驱动的 awareness 动态通道贡献显著（防护恰好在传播强期加大），而本文显著性通道被 S 型中点锁在饱和区。改进路径：响应函数与 prevalence 耦合再设计。

### 实验6：行为参数敏感性（κ×η，10 次重复/组）

| κ \ η | 0.00 | 0.15 | 0.30 | 0.50 |
|-------|------|------|------|------|
| 0.5 | 46.5 | 47.8 | 47.8 | 47.8 |
| 1.0 | 40.7 | 40.9 | 40.5 | 40.0 |
| 1.5 | 35.2 | 34.5 | 34.6 | 31.5 |
| 2.0 | 25.8 | 25.4 | 25.7 | 28.7 |
| 3.0 | 21.0 | 21.2 | 20.0 | 18.9 |

（表中为峰值降低%，零防护参照）效应在 κ≤1.0 时稳健（40%–48%）；κ 越大响应越接近阶跃、低风险基线防护越低，效应越小。行为惯性 η 影响总体有限（最大约 3.7 个百分点）。

### 消融实验（归因审计，5 条件 × 10 配对重复，床位 50/ICU 10，α=1.0）

| 条件 | 峰值感染 | 峰值防护 | 延后入院 |
|------|---------|---------|---------|
| baseline | 149.7 ± 14.0 | 0.371 | 202.7 ± 61.6 |
| no_info_saliency | 144.9 ± 11.8（-3.2%） | 0.342 | 196.5 ± 42.9 |
| no_behavior_feedback | 220.6 ± 17.9（**+47.4%**） | 0.000 | 432.0 ± 33.7（+113.1%） |
| no_hospital_constraint | 149.7 ± 14.0（0.0%） | 0.371 | 0.0（-100%） |
| no_mosquito | 141.6 ± 18.6（-5.4%） | 0.369 | 147.5 ± 61.5 |

**关键发现**：行为反馈是最关键组件；信息显著性单通道贡献在噪声内；床位约束不影响传播、只影响延后入院（此前版本的"+18.25%"是单次运行随机流分叉的伪效应，已用配对重复消除）；蚊媒通道贡献峰值约 5.4%。

## 再生协议

全部结果由统一协议一次性生成，保证论文、README、结果文件三者一致：

- **种子**：`seed = BASE_SEED×1000 + run_index`（`experiments/protocol.py`）
- **代码版本**：每次运行自动记录 git commit 到 `results/RUN_MANIFEST.yml`
- **依赖**：`requirements.txt`；运行时版本记录于 RUN_MANIFEST
- **结果文件**：规范命名（无版本后缀），历史版本由 git 管理
- **统计口径**：Welch t（不假设方差齐性）；消融变化% = (消融均值 − 基线均值)/基线均值 × 100，正值 = 移除后指标上升
